The selected approximations are as follow:
Diag(i, j, f): given the index of a sparse tensor i and j, we can diagonalize the tensor into blocks of a smaller factor. E.g. given dimensions of the sparse tensor as d, then if d[i] and d[j] have (block) sizes equal to 8 and 32, then the factors that we can pick from could be 2, 4, and 8. There are some invalid and no-op choices which we must mask:
- i and j must be from oposite partitions (primal vs out dimensions)
- dimension (block) sizes co-prime or pure (both one)
- diagonal indexes must choose their already defined other diagonal index
- factoring by 1 (no-op)
- a dense index i must have a dense index in the opposite partition (derived from above)

What this means is that there are a couple scenarios where there may be no valid pair e.g.: all diagonals are pure and/or co-primes or the out dimensions is empty.

Compress(i, agg): given the axis of the value of a sparse tensor i, then we can aggregate along this axis using a chosen function, and the sparse tensor updates its metadata as to remove all instances of this axis, and demote later axes by one (i.e. making these indexes implicit). If all dimensions are made implicit, we are left with a value that is None, however we store the fully aggregated value in the scalar multiplier attribute of the sparse tensor.

Quantize(dtype): given different quantization coverage we will scale the value to the allowable range, apply the quantization on the value, and then apply the inverse to the scalar multiplier attribute of the sparse tensor. E.g. quantizing a float32 value to int8 have vastly different maximum values, which need compensating: 3.4028234664\times10^{38} and 2.147483647\times10^{9} respectively.
